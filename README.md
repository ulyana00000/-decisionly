# Третя сторона — landing page

Статичний односторінковий сайт проєкту «Третя сторона» на HTML + CSS + JavaScript.

## Запуск
1. Відкрийте `index.html` у браузері.
2. Замініть `https://t.me/your_decisionly_bot` у `index.html` на актуальне посилання на Telegram-бота проєкту.

## Структура
- `index.html` — структура та тексти сторінки
- `styles.css` — стилі, сітки та адаптивність
- `script.js` — мобільне меню та плавна поява блоків під час скролу
