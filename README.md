# Decisionly landing page

Статичний односторінковий сайт на HTML + CSS + JavaScript.

## Запуск
1. Відкрийте `index.html` у браузері.
2. Замініть `https://t.me/your_decisionly_bot` у `index.html` на реальне посилання на Telegram-бота.

## Структура
- `index.html` — структура сторінки
- `styles.css` — дизайн і адаптивність
- `script.js` — мобільне меню та анімації появи
- `design-reference.png` — згенерований референс макета
